Send a time-limited link showing your vehicle’s location, navigation destination, arrival time, and speed. Tesla ETA uses the MQTT data TeslaMate already publishes.

FEATURES

What a viewer sees.

01

Arrival estimates

Minutes remaining, local arrival time, distance, speed, battery estimate, and traffic delay sit together on one screen.

02

Vehicle and destination

See the vehicle and the destination set in Tesla navigation. The map follows updates, or you can move it and recenter later.

03

Time-limited links

Choose a vehicle and expiry, share the link, and revoke it whenever you need to. The admin page shows how many viewing tabs are open.

04

Fleet map for admins

The admin list shows every vehicle. Select one to follow its location, or show all vehicles with available locations on the map.

DEPLOYMENT

Deploy with Docker Compose.

Add the container to your TeslaMate Compose stack, or run it on its own. Configure the broker and create links from the admin page.

$docker compose up -d --build tesla-eta

Command shown for an existing TeslaMate Compose stack.
